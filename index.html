Desktop Gadget

Windows 바탕화면 위에 자연스럽게 통합되는 올인원 생산성 가젯 보드입니다.
Google Calendar 및 Google Tasks 실시간 동기화, 날씨 예보, AI 공문서 분석, 디지털 판서 기능을 한곳에서 제공합니다.

📅 Google 캘린더 & 할 일 동기화

Google Calendar API v3 및 Google Tasks API와 실시간 양방향 동기화됩니다. 드래그 앤 드롭 일정 이동, 사전 알림 팝업, 기기 간 실시간 데이터 유지를 지원합니다.

🤖 AI 공문서 자동 분석 비서

복사된 공문 텍스트를 Gemini AI로 분석하여 핵심 이행 과제와 제출 기한을 자동으로 추출하고, 원클릭으로 Google Tasks 일정에 등록합니다.

🌤️ 실시간 기상 및 대기질 예보

기상청 단기예보 및 에어코리아 데이터를 연동하여 현재 지역의 날씨, 시간별 예보, 미세먼지·초미세먼지·오존 등급을 직관적으로 안내합니다.

🔒 프라이버시 자리비움 보호

원클릭 블러 가림막 모드와 4자리 보안 PIN 잠금을 통해 자리 비움 시 개인 일정과 메모 노출을 안전하게 차단합니다.

✍️ 교육용 스마트 판서 노트

15칸 원고지, 영어 4선지, 백지 노트를 즉시 호출하여 화면 위에서 직관적인 판서와 학습 지도를 수행할 수 있습니다.

🧲 자석 스냅 & 바탕화면 결속

Windows 바탕화면 레이어에 안정적으로 결속되며, 스마트 가이드 안내선과 자석 스냅 기능으로 깔끔한 위젯 배치를 지원합니다.
